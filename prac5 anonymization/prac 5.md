# Practical 5: Anonymization Techniques

## Aim 

To study data anonymization techniques such as k-anonymity, differential privacy and data masking, and apply them to a real-world dataset.

## Requirements

- Computer/Laptop
- Python 3.x
- VS Code / Jupyter Notebook
- Pandas
- NumPy
- Sample dataset

## Introduction

Data anonymization is the process of modifying personal data to reduce the possibility of identifying individuals. Common techniques include k-anonymity, differential privacy and data masking.

## Procedure

1. Load the dataset using Pandas.
2. Identify direct and indirect identifiers.
3. Mask sensitive information such as phone numbers.
4. Remove direct identifiers and generalize quasi-identifiers.
5. Apply k-anonymity concepts to the dataset.
6. Calculate a statistical value and add controlled noise for differential privacy.
7. Compare the original and transformed data.
8. Observe the privacy improvements.

## Result

The dataset was successfully anonymized using data masking, generalization/k-anonymity and differential privacy techniques.

## Conclusion

Data anonymization reduces the risk of identifying individuals from datasets. k-anonymity, differential privacy and data masking provide different approaches to protecting personal information while retaining useful data for analysis.
